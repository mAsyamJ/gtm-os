# Creative — AGENTS.md

Mission: Image/video creative production. Tenant is mandatory. Root `AGENTS.md` always applies.

**Inputs:** approved narrative + valid brand tokens + fully licensed source assets.

**Outputs:** editable graphics, source video timeline, renders, manifest, accessible captions and QA.
