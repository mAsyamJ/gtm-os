# Last30Days and source coverage

V4 uses a bounded project collector with the existing global capability inventory as an audited reference. It does not invoke the full Last30Days or Agent Reach CLI with inherited authentication. Installed components are not automatically live integrations.

| Channel | Current scope | Exclusions / limitations |
|---|---|---|
| Pinned public GitHub files | Real keyless collection and source review | Documentary proof; historical receipts do not prove present deployment state |
| HN Algolia | Real eight-topic rolling query collection | Source relevance excludes author-only matches; no matching results is not evidence of no discussion |
| Official Kuru/Monad/Uniswap/Helius/about/docs pages | Individually registered static public reads | Coverage is partial; redirects/access denial block the target |
| Last30Days | Existing pinned date utilities and query/coverage design; V3 offline component replay retained | Full provider orchestration inactive; its GitHub token discovery path is not executed |
| Agent Reach | Existing prescribed feedparser via parser-only worker | Broad doctor, install/config and credential channels not run |
| RSS | Bounded parser available for an individually admitted feed | No live RSS feed is claimed from fixture success; initial registry has no active feed |
| Scrapling | Existing Selector parser-only adapter available | No Fetcher, browser, stealth or challenge bypass |
| X / paid providers | Denied | No cookie, login, GraphQL or paid API coverage |

## Clocks and reproducibility

Each collection receipt records its actual UTC start/end and source collection times. A rolling window spans exactly 30 times 24 hours and includes its exact boundaries. Publication dates come from explicit metadata/feed/API timestamps. Modified timestamps, crawls, seed dates and filesystem times do not substitute for publication time. Undated or old material is `BACKGROUND`.

The first live runs collected real official/reference documents. Their source-dated coverage is sparse and mostly background. The first two editorial opportunities are therefore evergreen mechanism/engineering explanations, not claims about a last-30-days market trend. Initial HN queries yielded no relevant matched records for most domains. This is disclosed in collection/synthesis receipts, not replaced with synthetic market data.

Collection results and query attempts are separate: a successful query may have zero eligible records. Recent collection receipts include `queries` with result counts and errors; earlier preserved attempt receipts predate that field. Do not infer full platform coverage from one completed run.

## Quotas and rights

Every HTTP request, including robots and failed/uncertain attempts, consumes the durable first-sprint reservation. Actual stored application body bytes exclude TLS/header overhead. No redirects are followed. Robots delays from two to five seconds are honored rather than flattened to one second. Bodies with unsupported content encodings are denied.

Response hashes bind retrieved HTTP body bytes, not rendered page truth. Excerpts are separately hashed. Source licensing is recorded independently: MIT product material has explicit licensing; other pages use bounded internal-review excerpts with undetermined republication rights. Owner quotation/rights review remains required before publishing.

New sources require individual host/path/query policy review. A seed URL does not authorize a host. New source policy never overrides the X prohibition. Exhausted quotas and unavailable sources return explicit blockers, with no paid/authenticated fallback.
