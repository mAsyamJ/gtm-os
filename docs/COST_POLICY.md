# Cost and authorization

Default hard cap of $0 on charged APIs, including X. Estimate charges from current provider docs and account scope before any paid request; never use stale hard-coded rate as truth. Explicit human authorization required for enabling spend, scheduler/hosting changes and all outbound social actions. Record budget, predicted cost, actual billable call, provider receipt, retry outcome and monthly rollup. Report unknown monetary cost as UNKNOWN rather than $0. Self-host software may be free to license but costs compute and platform API fees.
