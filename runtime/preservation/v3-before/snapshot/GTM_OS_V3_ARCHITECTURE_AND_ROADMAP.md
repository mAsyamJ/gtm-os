## Architecture principles
1. Global discovery/skill adaptation remains global; marketing policy and tenant state remain local.
2. Agent Reach and Scrapling are **research adapters**, not rights to automate or scrape restricted websites; X Terms prohibit scraping without written consent.
3. Prefer allowed keyless sources and first-party evidence; use owner-controlled manual posts and manual analytics exports for X.
4. Humanizer follows, never replaces, fact verification; preserve numeric and personal claims.
5. Harness² recursively improves the harness; cannot modify global live config without owner approval.
6. Quarantine Harness²: upstream Codex executor disables sandbox and has unrestricted network; only run the offline demo or hardened isolated worker with no authenticated apps.
7. Publishing outputs are audited manual handoff packages, not automatically transmitted posts.
