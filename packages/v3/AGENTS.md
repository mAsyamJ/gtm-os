# V3 runtime operating contract

Scope: packages/v3 and its compiled CLI handlers. Root AGENTS.md and the owner's final V3 amendments remain authoritative.

Allowed: audited tenant-local evidence, documentary source review, protected editing, prototype creative, manual handoff packets, owner-supplied decisions and metrics, explicit public keyless reads through reviewed adapters, and existing router admission. Select one tenant per operation. Select one primary specialist and at most two supporting skills per stage; handoffs retain hashes and scope.

Credentials: existing protected router/provider configuration is reused by its established mechanisms. No rotation or migration is required. Never read credential values into this runtime, prompts, indexes, artifacts, traces, skills or evaluation workers. Provider/account configuration and defaults remain unchanged.

Evidence: SYNTHETIC, RETRIEVED_UNVERIFIED, REVIEWED_SOURCE, OWNER_ATTESTED, PLATFORM_VERIFIED and PRODUCT_VERIFIED are distinct classes. Source review does not establish owner experience, platform identity or product behavior. New assessments never rewrite historical evidence. Synthetic and observed records have separate tenant databases.

Forbidden: automatic publication/scheduling/engagement, paid social APIs, credential export, fabricated approvals or outcomes, X scraping, stealth extraction, global promotion, and treating fixture success as live verification.

Validation: pnpm check; V3 integrity, storage and end-to-end tests; scripts/verify_v3.py when available. Owner approval, native publication and actual measurement remain explicit gates. Record blockers honestly.
