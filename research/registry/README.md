# V4 public source and seed registry

The root people/project CSVs remain the canonical owner-supplied seeds. Imports preserve original fields and tenant relevance. A seed URL is a discovery pointer, not an authorized source policy or verification result.

`config/v4-sources.json` contains individually admitted keyless endpoints: host, path prefixes/query keys, research pillar, access mode, licensing/excerpt classification and review date. New entries require policy/terms/robots review. X remains prohibited even if accidentally added.

Timestamped watchlist exports distinguish reviewed identity from reviewed current role. Never count the same person twice across tenants. Missing handles, stale roles and unverified recent content remain unknown.
