# Isolated improvement track

Project-owned adapters only. Upstream Harness² stays byte-for-byte pinned and inert until
loaded in a rootless, network-disabled worker. The host launcher must not import upstream
configuration, which can load `.env`. No global instructions, credentials, production
repositories or grading answers enter the worker. Offline means no hosted model requests.
Synthetic contract results never establish live connector or business performance.
Promotion requires separate observed brand cycles, sealed evaluation, security, rollback,
independent review and exact owner authorization. No automatic promotion is implemented.
